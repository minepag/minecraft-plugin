# Segurança

Encontrou uma falha de segurança no plugin ou no protocolo da MinePag? Não abra uma issue pública. Escreva para **security@minepag.com.br** com os passos para reproduzir, a versão do plugin e da plataforma (Paper, Folia, Purpur ou Spigot).

Respondemos em até 3 dias úteis e combinamos com você a data de divulgação depois da correção.

O token do servidor fica em `plugins/MinePag/data/credentials.yml`. Nunca o publique em issues, logs ou prints.
